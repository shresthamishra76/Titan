# Learning Notes

Per [PRD.md's Learning Track](../../PRD.md#learning-track), this project starts from zero C++ experience. This directory tracks the C++/CUDA concepts learned alongside each Milestone 1–2 issue — RAII, ownership, templates, move semantics, threading, SIMD, and eventually CUDA memory/kernel model.

One note file per concept or per issue is fine — whatever keeps the progression legible for an external reader.
